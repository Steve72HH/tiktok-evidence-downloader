# Security Policy

## Responsible Use

This tool is intended for local documentation and preservation of publicly
available TikTok videos where the user has a legitimate reason to save evidence.

Do not use this tool to harass people, bypass access controls, collect private
data, or redistribute copyrighted or illegal material.

## Reporting Issues

Please open a GitHub issue for bugs or security concerns. Do not include private
tokens, personal data, downloaded evidence files, or sensitive URLs in public
issues.
